# Titanic Survival Prediction: EDA & Logistic Regression 🚢

## Overview
This repository contains a complete machine learning workflow using the classic Kaggle Titanic dataset. The objective is to predict passenger survival by rigorously cleaning the raw data, conducting exploratory analysis, and building a Logistic Regression classifier. 

* **Language:** Python
* **Environment:** Jupyter Notebook (VSCode)
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn
